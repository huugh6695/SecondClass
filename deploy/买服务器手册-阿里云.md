## 2. 下单步骤（阿里云）

### 2.1 打开活动页

浏览器打开：

```
https://www.aliyun.com/activity/ecs/99program
```

> 也可以在阿里云首页搜「**99 计划**」或「**ECS 99**」。

### 2.2 找到"经济型 e 实例 99 元/年"

页面上会看到这个套餐卡片，核对这几个数字**必须完全一致**：

| 项 | 应该显示 |
|---|---|
| 实例类型 | **经济型 e 实例** |
| CPU / 内存 | **2 核 2G** |
| 带宽 | **3M 固定带宽**（不限流量）|
| 系统盘 | **40G ESSD Entry 云盘** |
| 价格 | **99 元/年** |

> ⚠️ 如果页面显示的是「轻量应用服务器 38 元/68 元」——**不要点它**。
> 理由见 `DEPLOY.md §2`：轻量不能转 ECS、备案只支持 1 个域名、带宽是共享峰值。

### 2.3 点"立即购买"，逐项确认

下单页有几个下拉框，**每一项都对照下表**：

| 页面选项 | ✅ 选什么 | 🔴 为什么 / 注意 |
|---|---|---|
| **地域（Region）** | **离你最近的中国大陆城市**（如华东1杭州、华北2北京）| ⚠️ **千万别选"香港/新加坡"等境外**！境外访问慢，且以后想迁回国内要重做 |
| **可用区** | 默认（随机）即可 | 随便选，不影响 |
| 实例规格 | **ecs.e-c1m1.large**（2核2G）| 活动页一般已锁死 |
| **镜像** | 🔴 **Ubuntu 22.04 64位** | 选「公共镜像」→「Ubuntu」→ 找 **22.04**。**别选 24.04**（命令可能有出入）、**别选 CentOS** |
| 系统盘 | 40G ESSD Entry，**默认** | 不用改 |
| 数据盘 | **不要买** | 40G 够用了，附件长大了再加 |
| **公网 IP** | 🔴 **勾选"分配公网IPv4地址"** | 不勾就没法从外面访问 |
| 带宽计费 | **按固定带宽 3M** | 活动已配好 |
| **登录凭证** | 🔴 **选「自定义密码」**，设一个**强密码** | ⚠️ **别选"创建后设置密钥对"**——初学者用密码登录最省事。密码**务必记在本子上** |
| 购买时长 | **1 年** | 99 元是一年的价 |
| 自动续费 | 可勾可**不勾** | 建议**先不勾**，等用顺了再说 |
| 数量 | **1 台** | |

> 🔴 **密码怎么设**：至少 8 位，**含大写 + 小写 + 数字 + 符号**（如 `Sc@2026#Host`）。
> 这个密码是**服务器管理员密码**（root 的 SSH 密码），**丢了很麻烦**（要重置需重启机器）。
> **买完立刻记到记事本 / 密码管理器里。**

### 2.4 付款

勾选协议 → 付款 → **别关页面**，等它跳转到「支付成功」。

## 3. 买完之后：拿到这 3 样东西

付款成功后，点「**控制台**」→「**云服务器 ECS**」→「**实例**」，你会看到刚买的那台机器。**把这 3 样抄下来给我**：

| # | 东西 | 在哪看 | 长什么样 |
|---|---|---|---|
| 1 | **公网 IP** | 实例列表里"IP地址"列，**公网**那个 | `123.45.67.89` |
| 2 | **登录用户名** | 固定是 `root` | `root` |
| 3 | **登录密码** | 你刚才自己设的 | （你的密码）|

> 这三样就是"服务器的门牌号 + 钥匙"。
> 🔴 **密码别贴到聊天窗口里**（尤其是公开的地方）。告诉我 IP 就行，密码我自己不存。

### 顺手做一件事：设置安全组

在控制台左侧找「**安全组**」→ 找到这台机器绑定的安全组 →「**配置规则**」→「**入方向**」，
**只保留这 3 条**：

| 端口 | 授权对象 | 说明 |
|---|---|---|
| 22 | 你的常用 IP（不知道就先填 `0.0.0.0/0`，以后收紧）| SSH 登录 |
| 80 | `0.0.0.0/0` | 网站（HTTP）|
| 443 | `0.0.0.0/0` | 网站（HTTPS）|

> 🔴 阿里云买完默认可能已经开了 22，**但 80/443 要自己加**。
> ⚠️ **千万不要**加 3306 / 6379 / 8080（见 `DEPLOY.md §2`）。

## 4. 域名和备案（可选，但建议一起办）

### 要不要买？

| 你的情况 | 建议 |
|---|---|
| 以后**要给学校 / 同学用** | ✅ **现在就买**。因为备案要 **1–4 周**，越早提交越早能用 |
| 只是自己学、自己看 | 可以先不买，用 `http://公网IP:8080` 直接访问 |

### 买域名

1. 阿里云控制台搜「**域名注册**」；
2. 搜你想要的域名（如 `scesc.top`、`secondclassroom.cn`）；
3. **便宜的就行**：`.top` / `.xyz` 首年常只要 10–30 元，`.cn` 约 30–60 元/年；
4. 买完**立刻做实名认证**（域名也要实名，1–2 天通过）。

> ⚠️ 买域名时**别顺手勾 CDN / 云解析付费版 / 邮箱**——用不上。

### 备案（拿到域名后）

1. 阿里云控制台搜「**ICP 备案**」→ 进入备案系统；
2. 按引导填：**主体信息**（你本人身份证）+ **网站信息**（就是这台服务器的公网 IP）；
3. 阿里云会**免费寄一块幕布**给你拍照（或用 App 拍），照做即可；
4. 提交后等 **3–20 个工作日**（各地管局不同）。

> 🔴 **备案期间，域名不能解析到服务器**（否则可能被拦）——所以之前说的"临时用 IP 访问"就是这段时间用的。
> 🔴 **备案要花钱吗**：**免费**。任何说"代办备案收费"的都是灰色服务，别碰。

## 5. 常见问题

| 问题 | 答案 |
|---|---|
| 买完发现选错系统了（选成 CentOS）| 可以在控制台「**更换操作系统**」重置成 Ubuntu（数据会丢，反正也是新的）|
| 忘了 root 密码 | 控制台「实例」→ 更多 → **重置实例密码**（**需要重启机器**才能生效）|
| 买了轻量服务器后悔了 | 🔴 **轻量不能转 ECS**。只能退（5 天内无理由，且看活动规则）或重新买一台 ECS |
| 活动页打不开 / 99 元已售罄 | 99 计划是长期活动但**可能限时**，换个时间再试；或看 `https://www.aliyun.com/daily-act/ecs/activity_selection` |
| 学生有更便宜的 | 学生认证后有 **300 元无门槛抵扣金** + 专属包（练手包 19 元 / 毕设包 339 元），入口 `https://university.aliyun.com`。⚠️ 但 99 计划**已经足够便宜且不用认证**，别为省几块钱折腾 |
| 2核2G 够不够？ | 你提过已在本机预演过：Java 占 300–500MB、MySQL 约 300MB、Redis 几十 MB。**2G 够跑，但偏紧**。若以后嫌卡，ECS 可原地升到 2核4G（轻量做不到）|
