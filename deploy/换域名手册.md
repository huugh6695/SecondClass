# 把 `http://<你的服务器IP>:8080` 换成域名 —— 完整操作手册

> **这份文档解决什么问题**
> 现在访问系统要记一串 IP 加端口。换成域名（比如 `https://sc.jiangjiang.cn`）之后，
> 地址栏干净、能上 HTTPS、面试时能直接说出口、简历里也能写。
>
> **写于 2026-10-28。** 当时的状态：系统已经真机上线（简单路线，无 Nginx / 无 HTTPS / 无域名），
> **系统最终给谁用还没决定**，所以本文只做流程说明，**暂不执行**。
>
> 如果哪天要动手，从 §1 的顺序往下做，别跳步 —— 跳步会白等 20 天。

---

## 0. 先说三件已经就绪的事（省得你重复劳动）

| 已经有的东西 | 在哪 | 说明 |
|---|---|---|
| 前端**没有硬编码 IP** | `static/js/api.js:19` → `const BASE = ''` | 请求发的是相对路径 `/api/xxx`，页面在哪个域名下就打哪儿。**换域名不用改前端代码。** |
| 后端**没有跨域配置** | 全项目搜 `Cors` / `allowedOrigin` → 0 处 | 因为前端是 Spring Boot 自己伺服的，天然同源。所以也**不需要加域名白名单**。 |
| Nginx 配置文件**已经写好** | `deploy/nginx-second-classroom.conf` | 里面已经处理好两个要命的坑：`client_max_body_size 10m`（不然传 3MB 照片就被挡成 413）、`X-Forwarded-For` 用 `$remote_addr` **覆盖**（防伪造 IP 进审计表）。只要把 `YOUR_DOMAIN` 换掉。 |

**唯一的例外**：备案通过后，网站底部**必须**挂备案号（法律要求），这一步要改 HTML。
详见 §6。所以准确说法是「换域名基本不用改代码，只有备案号那一下要动一次 `index.html`」。

## 1. 全景：一共 5 步，卡在第 3 步

```
① 买域名            10 分钟      阿里云 / 腾讯云，几十块一年
② 实名认证          1~2 天       传身份证，自动审
   └─ 等 3 天 ─────────────────  🔴 官方要求，等不够会被管局驳回（见 §3）
③ ICP 备案          1~3 周       🚧 唯一的真卡点，等管局审核
④ DNS 解析          10 分钟      A 记录 @ → <你的服务器IP>
⑤ Nginx + HTTPS     半小时       80/443 转发到 8080，certbot 免签证书
```

**顺利的话 1~2 周，慢的话 3 周以上。** 除了第 ③ 步，其他都是当天能完事的。

### 一条重要的分叉：先不备案会怎样

阿里云官方原文（备案 FAQ）：

> 如果您未在阿里云完成网站备案，直接将域名解析至阿里云中国内地（大陆）服务器上，
> 将被阿里云监测系统识别并**阻断网站的访问服务**，提示您需先完成备案操作。

所以「不备案用域名」不是“技术上不行”，而是**不合规、随时会被断**。
实践中被拦的通常是 **80 / 443**，8080 这类高位端口常常还能通 —— 但那属于撞运气，
**不能当作方案**。如果只是自己看、给面试官看一眼，可以临时这么用；一旦要给真人用，必须备案。

## 2. 第 ① 步：买域名

**在哪买**：阿里云（`wanwang.aliyun.com`）或腾讯云（`dnspod.cn`）。跟服务器同一家最省事
（备案时不用来回切账号，DNS 也不用改 NS）。

**选什么后缀**：

| 后缀 | 大致价格 | 说明 |
|---|---|---|
| `.cn` | 约 30 元/年 | 便宜、国内认可度高，个人可注册 |
| `.com` | 首年 30~70，续费约 80 | 最通用，好名字基本被占完 |
| `.top` / `.xyz` | 首年几块到十几块 | 便宜，但看着像临时项目 |
| `.io` / `.dev` | 几百元/年 | 贵，技术圈好看，不必要 |

**建议**：`.cn` 或 `.com`，一年几十块的事，别为省钱选个看着像钓鱼站的冷门后缀。
**买 1 年就够**，用得好再续。

**起名字的注意点**：
- 别用纯数字、别用别人的商标（比如 `bilibili`、`tencent` 这种，会被投诉收回）
- 学校的名字（`aust`）**不要**随便用 —— 除非学校授权，否则属于冒用单位名称
- 想好一个能长期用、且说得出口的（面试时会念出来）

## 3. 第 ② 步：实名认证，然后**等 3 天**

买完域名第一件事是在域名商后台做**实名认证**（传身份证正反面）。不做的话域名会被
`serverHold`（解析暂停），等于白买。

🔴 **然后必须等。** 阿里云官方文档原文：

> 域名实名认证、修改/过户完成后，需要**约三天时间**将实名认证信息入库管局。
> 建议您在实名认证完成后**至少等待三天**再申请 ICP 备案，避免管局审核时
> 无法获取最新域名实名认证信息。

等不够会怎样：提交上去，管局驳回，理由写「**该域名不存在注册商验证库中**」。
驳回一次就要重排一次队 —— 白白多等一周。

**所以实操顺序是**：D1 买域名 + 实名 → D2~D4 什么都不用做（正好用来准备 §4 的材料）→ D5 提交备案。

## 4. 第 ③ 步：ICP 备案（唯一的卡点）

### 4.1 先自查这 5 条，缺一条就别提交

- [ ] **域名已实名认证，且已满 3 天**（见 §3）
- [ ] **域名后缀在工信部批复名单里** —— `.com / .cn / .net / .top / .xyz` 这些主流后缀都没问题；
      特别冷门的先去工信部「域名注册管理机构名单」查一下
- [ ] **服务器是包年包月，剩余时长 ≥ 3 个月，且买了公网带宽**
      🔴 官方明确：**按量付费实例开不出备案服务号**。
      你的 ECS 是「经济型 e」，300 元学生券全抵的那种，**大概率是包年包月**，
      但要自己去控制台确认（实例详情里看「付费方式」和「到期时间」）。
      剩余不足 3 个月就先续费。
- [ ] **身份证在手边**，手机号能收短信（工信部要在 **24 小时内**完成短信核验，超时要重来）
- [ ] **想好了「网站名称」** —— 这条最容易翻车，见 4.3

### 4.2 在哪提交、怎么走

阿里云：控制台 → 搜索「备案」→ 进入 **ICP 代备案管理系统**（`beian.aliyun.com`）
→ 「开始备案」→ 按向导填。

需要准备的材料（个人备案）：
- 身份证正反面照片
- 《网站备案真实性核验单》（系统里能下载，需要**手写签名**后拍照上传）
- 部分省份还要域名证书（域名商后台能下载 PDF）
- 核验方式：按系统提示，可能是 APP 人脸核验，或阿里云寄幕布拍照（现在多数是 APP 刷脸）

流程和时间：
```
提交 → 阿里云初审（1 个工作日，会打电话核验）
     → 工信部短信核验（24 小时内点链接+填验证码）
     → 管局审核（≤ 20 个工作日）
     → 下发备案号
```

**提交后手机一定要保持畅通** —— 阿里云初审会打电话，没接就驳回，又要重排。

### 4.3 🔴 「网站名称」到底填什么 —— 这是决定成败的一条

规则：**网站名称必须和备案主体对得上。**

| 备案主体 | 你能填的名称 | 你**不能**填的 |
|---|---|---|
| **个人**（用你身份证） | 「江江的学习笔记」「依帆的技术小站」这类**个人性质**的 | ❌「第二课堂学时答疑系统」❌「XX学院学工系统」—— 一听就是单位服务，会被驳回 |
| **单位**（学校/学院的法人证书） | 可以填系统真名 | 需要学校的**事业单位法人证书**、**授权书**、**公章** |

**所以这里有个死结，得先说清楚：**

你这个系统是「给同学提交学时工单」的，**本质是单位服务**。
但单位备案要学校配合（法人证书 + 授权书 + 公章），你手上没有。

**两条出路**：

1. **只做个人用途的演示站**（推荐，也最现实）：
   不对外宣传、不给同学真用，只做作品展示。
   备案填个人主体 +「个人技术学习笔记」这类名称，网站上放个「演示环境，数据仅供测试」的提示。
   这样能过，但**名不副实** —— 别拿它当正式服务用。
2. **走学校**：找学院/团委的老师，用单位的法人证书备案。
   流程长（要盖章、要老师当负责人），但备案下来就是正经系统。
   **注意：备案负责人要承担内容责任，老师未必愿意签字。**

⚠️ **在“给谁用”没定下来之前，不要提交备案。** 主体填错要注销重来，
周期比第一次还长（要先注销主体，再重新提交）。这就是本文档写于“暂不执行”状态的原因。

### 4.4 备案地按什么算

**按你身份证上的地址（主体所在地）**，不是服务器所在地。
<你的服务器IP> 在杭州，但如果你身份证是别的省，备案就走你所在省的管局，
备案号也是那个省的简称（如「浙ICP备」/「苏ICP备」）。

## 5. 第 ④ 步：DNS 解析

备案通过后（其实解析可以先配，只是没备案访问会被断），去域名商后台：

**阿里云**：控制台 → 域名 → 找到域名 → 「解析设置」→ 「添加记录」

| 记录类型 | 主机记录 | 记录值 | TTL |
|---|---|---|---|
| `A` | `@` | `<你的服务器IP>` | 600（10 分钟） |
| `A` | `www` | `<你的服务器IP>` | 600 |

- `@` 表示「域名本身」，即 `yourdomain.cn`
- `www` 表示 `www.yourdomain.cn`
- 想用子域名（`sc.yourdomain.cn`）就把主机记录写成 `sc`

**验证解析生效**（在你自己的电脑上，不是服务器上）：
```bash
nslookup yourdomain.cn
# 或者
ping yourdomain.cn
```
看到返回 `<你的服务器IP>` 就对了。没生效就等，TTL 最长 10 分钟。

🔴 **别在服务器上验证解析** —— 服务器自己的 DNS 可能缓存旧记录，看着像没生效，实际已经好了。
用手机 4G 网络打开 `http://yourdomain.cn:8080` 试一下，最准。

## 6. 第 ⑤ 步：服务器上装 Nginx + HTTPS

### 6.1 装 Nginx 并接入现成配置

在自己电脑的 Git Bash 里（**路径含空格，引号别丢**）：

```bash
# 1. 把已经写好的配置文件传到服务器
scp -i ~/.ssh/workbuddy_sc_ed25519 \
    "D:/basic codes/second-classroom/deploy/nginx-second-classroom.conf" \
    root@<你的服务器IP>:/tmp/sc.conf

# 2. 登录服务器
ssh -i ~/.ssh/workbuddy_sc_ed25519 root@<你的服务器IP>
```

在服务器上：

```bash
apt update && apt install -y nginx

# 把 YOUR_DOMAIN 换成你的真域名（三处会一起替换：server_name、日志名注释等）
sed -i 's/YOUR_DOMAIN/yourdomain.cn/g' /tmp/sc.conf
cp /tmp/sc.conf /etc/nginx/sites-available/second-classroom

# 启用这个站点，去掉 Nginx 自带的欢迎页（不去掉它会抢 80 端口）
ln -sf /etc/nginx/sites-available/second-classroom /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default

# 检查语法，然后重载（不是 restart，reload 不断连接）
nginx -t && systemctl reload nginx
```

**验证「Nginx → 后端」这条链路**（在服务器上跑，用 Host 头模拟域名访问）：
```bash
curl -s http://127.0.0.1/health -H "Host: yourdomain.cn"
```
应该返回 `{"code":0,"message":"ok",...}`。

再做一次**对照验证**，故意绕过 Nginx 直接问后端：
```bash
curl -s http://127.0.0.1:8080/health
```
两条都通 = 两个环节都好。**哪条不通就说明问题在哪一层**：
第一条不通、第二条通 ⇒ Nginx 配置的问题；两条都不通 ⇒ 后端没起来（`systemctl status second-classroom`）。

### 6.2 安全组放行 80 / 443

阿里云控制台 → ECS → 安全组 → 配置规则 → 入方向，添加：

| 端口 | 协议 | 授权对象 | 用途 |
|---|---|---|---|
| 80 | TCP | 0.0.0.0/0 | HTTP（certbot 验证 + 自动跳 HTTPS） |
| 443 | TCP | 0.0.0.0/0 | HTTPS |

🔴 **这一步千万别忘。** 症状很好认：`ufw` 是 inactive、`systemctl status nginx` 是 active、
但外网 `Connection refused` 或超时 ⇒ **一定是安全组没放行**（详见 `ENV.md` 铁律 26）。

### 6.3 申请免费 HTTPS 证书

```bash
apt install -y certbot python3-certbot-nginx

# 一条命令：自动改 Nginx 配置，加 443、加 HTTP→HTTPS 跳转
certbot --nginx -d yourdomain.cn -d www.yourdomain.cn
```

过程中会问你邮箱（填真实邮箱，证书快到期会提醒）、是否同意条款（Agree）、
是否把 HTTP 跳转到 HTTPS（选 **Redirect**）。

**证书会自动续期**（certbot 装了个 systemd timer），但建议验一次：
```bash
certbot renew --dry-run
```

### 6.4 关掉 8080 对公网（收尾，但很重要）

现在 `http://域名:8080` 也能直接访问，这就**绕过了 Nginx**。后果是：
- 审计日志里的客户端 IP 变成 Nginx 之前的样子（其实也是真实 IP，但少了一层）
- 没上 HTTPS 的入口还开着，等于白配证书
- 上传体积上限（`client_max_body_size`）不起作用，还是 Spring 自己的 6MB

两种做法，**推荐第一种**：

**做法 A（彻底）**：让 Java 只监听本机，外部只能走 Nginx。
在 `/etc/second-classroom/env` 里加一行：
```
SERVER_ADDRESS=127.0.0.1
```
并在 `application-prod.yml` 里确保有 `server.address: ${SERVER_ADDRESS:0.0.0.0}`。
然后 `systemctl restart second-classroom`，再把安全组里的 8080 规则删掉。

⚠️ 副作用：**从此 Nginx 挂了就完全访问不了**（连"救急直连 8080"也没了）。
所以改之前先确认 `systemctl status nginx` 是绿的、`nginx -t` 通过。

**做法 B（省事）**：只在安全组里删掉 8080 的入方向规则，Java 还听 0.0.0.0。
外网进不来，但服务器本地还能 `curl 127.0.0.1:8080` 排查。**推荐这个**，风险更小。

## 7. 证书和备案号：还差最后一步

### 7.1 网站底部挂备案号（法律要求，必须做）

工信部要求：**已备案的网站必须在首页底部展示备案号，并链接到 `https://beian.miit.gov.cn/`。**
不挂被抽查到会被要求整改，严重的注销备案号。

本项目**唯一需要改代码的地方就在这里**。

`sites-enabled` 配置加一行还不够 —— 页面是 SPA，内容全由 JS 渲染，
最稳的做法是在 `src/main/resources/static/index.html` 的 `<div id="app">` **之后**加一段固定页脚：

```html
<footer class="icp-footer">
  <a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">
    浙ICP备2026000000号-1
  </a>
</footer>
```

（备案号换成你实际拿到的；省份简称跟着备案地走。）

⚠️ 加完必须做两件事：
1. **看一眼登录页和列表页的底部有没有被遮住 / 有没有把滚动条搞出来** ——
   `app.css` 里 `#app` 可能占了 `100vh`，加固定页脚会挤压它，需要配一条 CSS。
2. **把三处 `?v=` 一起改成当天日期**（`index.html` 两处 + `app.js` 里 import 的 `api.js`），
   否则用户浏览器还在用缓存里的旧页面，看不到页脚 —— 会以为没生效。
   验这个用 `bash verify/run-regression.sh 8117 verify-frontend.py`。

### 7.2 公安联网备案（备案通过后 30 天内）

ICP 备案下来后，还要在「全国互联网安全管理服务平台」（`beian.mps.gov.cn`）做**公安联网备案**，
30 天内完成。这一步很多人不知道，漏了会被提醒。
需要：ICP 备案号、网站域名、服务器 IP、负责人身份证。完成后会拿到一个公安备案号，
同样要挂在网站底部。

## 9. 出问题了怎么退回

配置改坏了、或者哪天想退回 IP 访问，**三步退回**：

```bash
# 1. 摘掉 Nginx 站点（Nginx 还在跑，但不再转发这个域名）
rm -f /etc/nginx/sites-enabled/second-classroom
systemctl reload nginx

# 2. 安全组把 8080 重新放行（控制台操作）

# 3. 访问 http://<你的服务器IP>:8080 —— 立刻恢复原样
```

域名和备案**不会因为这一步失效**，随时可以再接回去。
所以换域名这件事**风险很低**：真正不可逆的只有「买域名花的几十块」和「备案等待的时间」。

| **老师已经点头让学院用** | 走单位备案，找老师要法人证书 + 授权书 + 公章。这是最正规的路。 |
| **半年内都不确定** | 域名可以先买（好名字会被抢），**备案绝对先别提交**。 |
