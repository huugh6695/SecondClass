# 协作方式（配合 MEMORY.md 使用）

> **通用跨项目偏好（一步一指导 / 看不懂代码要大白话 / 不擅自改需求 / 新阶段先 AskUserQuestion / 用简体中文 / 阶段汇报用表格）
> 在 `~/.workbuddy/MEMORY.md`。** 本文件只放**本项目特有**的协作约定。

## 一、`requests.http` 两条铁律
- 🔴 **铁律①**：**禁用 `<单号>` 之类占位符**；**不留"必须先跑 A 才能跑 B"的隐藏变量依赖**（未赋值的变量会让请求根本没发出去，IDEA 只报"未替换的变量"）。
  写死示例值 + 注释说明。每组开头自带一条登录块（`client.global.set("token", ...)`），别指望用户先跑别处的登录。
- 🔴 **铁律②**：**新写完一组请求必须"当数据回放"验一遍**（验那几行字面文本，不是"我心里觉得对"）。
  通用脚本 `target/replay.py <端口> <组字母>`：
  1. **文本三查** —— 请求行格式 / 头行里混了中文标点（IDEA 会把它拆成两条）/ 用了没赋值的变量；
  2. **逐条真发**，**期望值从注释读**（`→ 400` 断 `body.code`；`→ HTTP 401` 断 HTTP 状态；无箭头默认 `200 + code=0`）；
  3. 兜底断言**无 5xx**。
  ⚠️ 带 `> {% ... %}` 响应处理器的块回放会**真落数据**；**写操作组结束前抹平状态**。
  ✅ **2026-10-11 补上两个能力**（此前带 `{{awo}}` 这类"响应处理器赋值"的组根本没法自动回放，
     URL 里会留下裸的 `%7B%7Bawo%7D%7D` ⇒ 必然 404；F / G / X / Y / Z 组都受影响）：
    ① **支持响应处理器变量** —— 解析 `client.global.set("x", response.body.data.<路径>)` 并存入 VARS，供后续块使用；
    ② **支持动态变量** `{{$timestamp}}` / `{{$uuid}}` / `{{$randomInt}}`（IDEA 原生也认），
       且**每次求值**（用 lambda），所以 requestId 写成 `"a-{{$timestamp}}-1"` 就能让这一组**重复回放**、
       每次都新开一张单，不会被上一轮的幂等/状态挡住。A 组就是照这个模板写的。
    ③ VARS 现在预置三个 token：`{{adminToken}}` / `{{token}}` / `{{staffToken}}`。
  ⚠️ 切块只认 `###` 分组，**行首 `>`（响应处理器）/ `<`（文件体）一律视为块结束** ——
  曾把它们拼进 JSON 正文，导致「POST + Content-Type + `> {% %}`」必然 400（踩过：E0 学生登录）。

## 二、成对破坏性动作（禁用 / 恢复）
🔴 **只写注释不够**：用户手点过 V7 没点 V8，学生被禁了一整天。
⇒ 要么别把破坏性步骤放进"随手可点"的手工清单，要么**让自动脚本兜住**。

## 三、组字母登记（加新组前先看这条）
`requests.http` 里 A = 回复/追问的敏感词检测（2026-10-11）、B = 登出黑名单（⑧④）、C = 敏感词缓存（⑧⑤）、**D = 提交时「疑似重复」提示（2026-10-14，D0~D8）**、E = 幂等（⑧③）、F~Z 已占用。**已无空闲字母。**
- 🔴 **D 组的近义测试对必须「换虚词、不换实词」**：算法比的是字面共享的实词数。`连续三天`↔`连着三天`、`扣款了`↔`把钱扣了` 稳过（交集 7 / 比例 78%）；而 `热水机`↔`热水器` 交集是 **0**（jieba 切成 `热水+机坏` vs `热水器`）。**别按"我觉得像"写断言**。
